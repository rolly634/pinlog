# ピンログ

マンホールポンプ・施工現場の巡回点検用に、地点をGPSで記録し、地区ごとに管理して、Googleマップでナビするスマホ向けWebアプリ(PWA)です。

アプリ: https://rolly634.github.io/pinlog/

## 地点を登録する

1. 現地で「記録」→「ここを記録」。
2. 種類(マンホールポンプ/施工現場。既定はマンホールポンプ)、ブロック、地区、ポンプ名、カギ種別(200番キー/丸カギ)、備考を入力して保存。
   - マンホールポンプは「ブロック(色つき)> 地区 > ポンプ名」の階層で管理します。施工現場はブロック・地区なしで、現場名だけを登録します。
   - 前回選んだブロック・地区が最初から入ります。新しいブロック・地区はその場で追加できます。
3. ブロックの名前・色、地区の名前・所属ブロックの変更は「一覧」→「ブロック・地区の管理」。
4. 一覧はブロック・地区・種類(カギ種別も)で絞り込めます。

## 巡回する

1. 「巡回」で地区を選んで「巡回を開始」(ブロック名にチェックすると中の地区をまとめて選択。施工現場は「施工現場(すべて)」でまとめて選択)(一覧の「選択」から個別に選ぶこともできます)。
2. 未点検の地点が、現在地から毎回並べ直されます(遠い順/近い順)。
3. 「残りをナビ」で、未点検の地点を次の10か所までGoogleマップに送ります。
4. 現地で「点検」:
   - マンホールポンプ: 運転時間(h)か消費電力量(kWh)のどちらか(初期は運転時間)と、MP1・MP2それぞれの最大電流(A)、その他メモを入力(すべて空欄でもOK)。項目ごとに、値が入っている直近の記録との差が表示されます。
   - 施工現場: メモなしで点検済みになります。
5. 時間切れならそのまま帰ってOK。巡回は「巡回を終了」を押すまで残り、次回は未点検の地点だけが表示されます。

## 出力

- 地図用ファイル(KML推奨・CSV・GPX): ブロック・地区の情報付き。マイマップでは「スタイル」→「データ列でグループ化」で「ブロック」を選ぶと色分けできます。
- 点検記録CSV: 地区と期間を指定して、点検日時・運転時間・メモを書き出せます(Excelで開けます)。
- バックアップ: 地点・地区・点検記録をまとめて書き出し/読み込み。

## Googleマップに表示する

1. 「出力」→ KML →「共有・保存」。
2. PCで https://www.google.com/mymaps を開き、地図を作成 →「インポート」でKMLを選ぶ。
3. Googleマップアプリの「保存済み」→「マイマップ」に表示されます。

## 注意

- データはスマホのブラウザ内に保存され、外部には送信されません。Chromeの「サイトデータを削除」で消えるため、定期的にバックアップしてください。
- 運転中の操作は避け、停車中に使ってください。
